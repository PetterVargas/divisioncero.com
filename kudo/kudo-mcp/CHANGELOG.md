# Changelog

## [0.1.2] - 2026-11-19

### Changed
- Modelo OSCAL mapping actualizado: las correlaciones de ISO 27001, NIST CSF, CIS, SOC 2, PCI DSS, CSA CCM y CSA AICM apuntan a las políticas nuevas del SGX (malware, vulnerabilidades, criptografía, clasificación, retención, IA, trabajo remoto, respuesta a incidentes, auditoría y acciones correctivas).

## [0.1.1] - 2026-11-19

### Changed
- Publicación en npm con Trusted Publishing (OIDC), sin token.

## [0.1.0] - 2026-11-19

### Added
- Servidor MCP de Kudo (stdio y Streamable HTTP) con herramientas de controles, documentos SGX, cobertura, modelos OSCAL (incluido mapping), POA&M, agentes y skills.
- 8 agentes de ciberseguridad como prompts y 16 skills como recursos.

## ¿Para qué es este curso?

Diseño, autenticación y protección segura de APIs.

## ¿Qué aprenderé?

- 🚀 **Fundamentos de Seguridad en APIs**: Conoce las arquitecturas de API y el OWASP API Security Top 10.
- 🚀 **Autenticación y Autorización en APIs**: Aplica OAuth 2.0, JWT y controla errores de autorización como BOLA y BFLA.
- 🚀 **Protección de Datos en Tránsito y en Uso**: Cifra las comunicaciones y valida entradas para evitar sobreexposición de datos.
- 🚀 **Gestión y Monitoreo de APIs**: Usa gateways, límites de tasa y monitoreo para detectar comportamiento anómalo.
- 🚀 **Gobierno del Ciclo de Vida de las APIs**: Inventaría tus APIs, gestiona versiones y aplica pruebas de seguridad continuas.

## Proyectos

Con este curso crearás, optimizarás, automatizarás o mejorarás con los siguientes proyectos:

- 🚀 Configurarás sistemas de protección de aplicaciones web (WAF, DDoS, rate limiting).

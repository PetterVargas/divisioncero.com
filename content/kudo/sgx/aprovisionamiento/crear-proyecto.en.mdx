---
title: Step 2 - Create the project
description: Generate the project's base structure with the Kudo CLI
---

Run the Kudo CLI to generate the project's base structure:

```bash tab="pnpm"
pnpm create @divisioncero/kudo-app
```

```bash tab="npm"
npm create @divisioncero/kudo-app
```

```bash tab="yarn"
yarn create @divisioncero/kudo-app
```

The CLI will ask you for the project name and create the directory with the whole content structure ready to customize.

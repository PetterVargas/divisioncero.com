## What is this course for?

Secure API design, authentication and protection.

## What will I learn?

- 🚀 **API Security Fundamentals**: Learn about API architectures and the OWASP API Security Top 10.
- 🚀 **API Authentication and Authorization**: Apply OAuth 2.0 and JWT, and control authorization flaws such as BOLA and BFLA.
- 🚀 **Protecting Data in Transit and in Use**: Encrypt communications and validate inputs to avoid excessive data exposure.
- 🚀 **API Management and Monitoring**: Use gateways, rate limits and monitoring to detect anomalous behavior.
- 🚀 **API Lifecycle Governance**: Inventory your APIs, manage versions and apply continuous security testing.

## Projects

With this course you'll create, optimize, automate or improve the following projects:

- 🚀 You'll configure web application protection systems (WAF, DDoS, rate limiting).

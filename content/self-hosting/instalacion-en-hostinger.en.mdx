## Installing on Hostinger

Before you start, review the [requirements](./requisitos).

<Callout type="warn">
  DivisionCero requires a **VPS**. Hostinger's shared hosting or web hosting plans are not compatible.
</Callout>

<Steps>
<Step>

### Create the VPS

From **hPanel**, purchase a **VPS** with Ubuntu LTS, choose the server location closest to your team and set up an SSH key for access.

</Step>
<Step>

### Configure the firewall

In the VPS security section in hPanel, enable the **Firewall** and allow only incoming SSH (22), HTTP (80) and HTTPS (443) traffic.

</Step>
<Step>

### Point your domain

Create a DNS record of type `A` that points your domain or subdomain to the VPS's public IP. If your domain is on Hostinger, do it from hPanel's **DNS Zone Editor**.

</Step>
<Step>

### Install DivisionCero

Connect to the VPS over SSH and follow the installation instructions in the [DivisionCero repository](https://github.com/PetterVargas/divisioncero).

</Step>
<Step>

### Activate your license

If you have a paid plan, activate the license provided by DivisionCero. This step isn't needed with the Community edition.

</Step>
<Step>

### Enable backups

Check in hPanel that the VPS **backups** are enabled and create a snapshot after the installation.

</Step>
</Steps>

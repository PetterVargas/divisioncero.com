## Support Tools

### OSCAL validators

To validate OSCAL documents generated from Kudo:

```bash
# Install the NIST OSCAL tools
npm install -g @nist/oscal-cli

# Validate the catalog
oscal-cli validate --schema=catalog kudo-catalog.json
```

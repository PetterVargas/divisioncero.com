---
title: "Multicloud and Hybrid Strategies and Their Security Governance"
description: "Governing security across several providers"
---

Operating across multiple cloud providers, or combining public cloud with on-premises infrastructure in a hybrid model, offers resilience and avoids dependence on a single provider, but multiplies the complexity of security governance, because each platform has its own identity model, its own native tools and its own terminology for equivalent concepts. Governing this complexity requires defining common security policies at the organizational level, and then translating them consistently into the specific configuration of each environment, relying on tools that centralize visibility over all providers in a single dashboard instead of reviewing each console separately. This matters because without that centralized governance it's easy for a control correctly applied in one provider to be completely missing in another. A practical example is requiring encryption of data at rest as a single corporate policy, and verifying compliance automatically in both the primary and the secondary cloud provider.

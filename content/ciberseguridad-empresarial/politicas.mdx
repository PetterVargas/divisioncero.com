Ruta en la aplicación: `/dashboard/policies`. Las políticas y demás documentos del sistema de gestión: responsable, fechas, estado y contenido.

## Pestañas

| Pestaña | Contenido |
| --- | --- |
| **Panel** | Políticas por estado y tipo, próximas revisiones y excepciones vigentes. |
| **Políticas** | El listado de documentos. |
| **Requerimiento** | Solicitudes de creación o cambio de documentos. |
| **Revisión** | Planifica y registra las revisiones. La última revisión realizada con versión define la versión vigente del documento. |
| **Excepciones** | Desviaciones documentadas y temporales de una política. |
| **Relaciones** | Actividades de auditoría, brechas de controles y riesgos relacionados con tus políticas. |

**Personalización:** Estados, Tipos de documento (Política, Norma, Procedimiento, Instructivo…) y Criticidad.

## Qué puedes hacer

- Crear documentos con contenido escrito en la plataforma, un **archivo adjunto** (PDF, Word, Excel, PowerPoint, texto o imagen de hasta 20 MB) o una **URL** (SharePoint, Google Drive…).
- Planificar revisiones con fecha planificada, revisores (usuarios o grupos) y registrar la fecha real y la **versión resultante**.
- Registrar **excepciones** con qué no cumple, justificación, riesgo aceptado, medidas o control compensatorio, solicitante, aprobador y vigencia. Al vencer, la excepción deja de cubrir la desviación; quien aprueba no puede ser quien la solicitó.
- Vincular políticas con controles, proyectos, unidades de negocio y requisitos de frameworks.
- Publicar documentos en el [Trust Center](/docs/ciberseguridad-empresarial/trust-center).
- Importar políticas, tipos de documento y revisiones desde Excel.

## Campos principales

| Campo | Descripción |
| --- | --- |
| Código / Nombre | Identificación del documento. |
| Tipo de documento | Del catálogo del equipo. |
| Responsable | Miembro a cargo. |
| Estado | Del catálogo de estados; cada uno equivale a una etapa del ciclo de vida. |
| Versión | La versión vigente, definida por la última revisión. |
| Fecha de publicación / Siguiente revisión | Control del ciclo de revisión. |
| Contenido, Archivo adjunto o URL | Dónde está el documento. |

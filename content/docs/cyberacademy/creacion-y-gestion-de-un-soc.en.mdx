## What is this course for?

Designing, implementing and operating a security operations center.

## What will I learn?

- 🚀 **SOC Fundamentals**: Learn SOC models and how to build their business case.
- 🚀 **SOC Design**: Design the SOC's technology architecture and use cases.
- 🚀 **People and Processes**: Define the team's shift structure and escalation processes.
- 🚀 **SOC Operations**: Manage alerts and integrate threat intelligence into daily operations.
- 🚀 **SOC Measurement and Improvement**: Measure the SOC's performance and chart its path toward greater maturity.

## Projects

With this course you'll create, optimize, automate or improve the following projects:

- 🚀 You'll implement a SOC (Security Operations Center) with SIEM/SOAR tools and automated threat hunting.
- 🚀 You'll configure advanced threat detection systems with machine learning and behavioral analytics.

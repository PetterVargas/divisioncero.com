---
title: "Types of Forensic Analysis: Disk, Memory, Network and Mobile"
description: "Each type of evidence requires its own analysis"
---

There's no single type of forensic analysis that covers every investigation; disk, RAM, network traffic and mobile devices require specialized techniques and tools because each preserves evidence differently. Disk analysis examines persistent data such as files, metadata and unallocated space where deleted items can be recovered; memory analysis captures the system's volatile state at the exact moment of acquisition, including active processes, open network connections and encryption keys that disappear when the device is shut down; network analysis reconstructs communication between systems from traffic captures or network device logs; and mobile analysis faces particular challenges such as default encryption and closed ecosystems that limit physical access to data. Choosing the wrong type of analysis, for example focusing only on the disk when the key evidence lived in volatile memory that's already been lost, can ruin an entire investigation.

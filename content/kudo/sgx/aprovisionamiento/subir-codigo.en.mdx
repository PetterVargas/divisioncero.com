---
title: Step 7 - Push the code to the repository
description: Initialize Git and push the project to your remote repository
---

Initialize Git and push the project to your remote repository:

```bash
git init
git add .
git commit -m "feat: initial SGSI setup"
git branch -M main
git remote add origin https://github.com/your-user/your-repository.git
git push -u origin main
```

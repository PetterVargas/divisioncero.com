---
title: "Enabling Technologies: ZTNA, SASE and CASB"
description: "Key tools for operating Zero Trust"
---

ZTNA, SASE and CASB are technologies that make it possible to put Zero Trust principles into operational practice, each covering a different need: Zero Trust network access, or ZTNA, replaces traditional VPNs by granting granular access per application instead of to the whole network; SASE converges network and security functions into a service delivered from the cloud for distributed users; and CASB provides visibility and control over the use of cloud applications that often escape traditional monitoring. Knowing these tools matters in practice because they're what translate Zero Trust theory into real controls applicable to remote users, branch offices and SaaS services. A common case is a company that replaces its corporate VPN with ZTNA, so a remote employee no longer gets access to the entire internal network when connecting, but only to the specific applications their role requires.

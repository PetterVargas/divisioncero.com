---
title: Step 3 - Run locally
description: Start the project on your machine to check that it works correctly
---

```bash tab="pnpm"
cd tu-proyecto
pnpm install
pnpm dev
```

```bash tab="npm"
cd tu-proyecto
npm install
npm run dev
```

```bash tab="yarn"
cd tu-proyecto
yarn install
yarn dev
```

Your app will be available at [http://localhost:3000](http://localhost:3000)

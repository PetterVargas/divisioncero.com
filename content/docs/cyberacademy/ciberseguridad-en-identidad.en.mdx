## What is this course for?

IAM, PAM and identity lifecycle management.

## What will I learn?

- 🚀 **Identity Management Fundamentals**: Learn IAM concepts and the digital identity lifecycle.
- 🚀 **Strong Authentication**: Implement MFA, passwordless authentication and Single Sign-On.
- 🚀 **Privileged Access Management**: Manage privileged access with credential vaults and session monitoring.
- 🚀 **Identity Governance**: Certify access and segregate duties to prevent access conflicts.
- 🚀 **Identity in Modern Environments**: Manage identity in hybrid and machine environments and with biometric verification.

## Projects

With this course you'll create, optimize, automate or improve the following projects:

- 🚀 Optimized corporate identity management.
- 🚀 You'll implement an identity and access management (IAM) system with multi-factor authentication.

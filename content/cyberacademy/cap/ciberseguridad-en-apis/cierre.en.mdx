## What we learned

We've brought you safely through the **API Cybersecurity Course**.

A quick recap of the places we visited and practiced:

- [X] API Architectures: REST, GraphQL and gRPC
- [X] OWASP API Security Top 10
- [X] API-specific attack surface
- [X] Resource-level access control and authorization
- [X] Common authorization errors in APIs (BOLA, BFLA)
- [X] Authentication mechanisms: API Keys, OAuth 2.0, JWT
- [X] Encryption and data protection in API communications
- [X] Excessive data exposure and field overexposure
- [X] Input validation and secure data handling
- [X] Rate limiting and abuse protection
- [X] Monitoring and detecting anomalous behavior in APIs
- [X] Using API gateways to enforce security controls
- [X] Versioning and secure deprecation of APIs
- [X] API inventory and discovery (Shadow APIs)
- [X] Continuous security testing for APIs

---
title: "Kudo Framework: Overview of Domains and Controls"
description: "Overview of the Kudo security framework"
---

The Kudo framework organizes an organization's security into clearly defined domains and controls, offering leaders a common structure for understanding which areas the security program covers, where gaps exist and how aspects such as risk management, incident response and organizational culture relate to each other, instead of seeing security as a scattered list of disconnected initiatives. Having this kind of reference framework helps leadership hold more structured conversations with the technical team, because it makes it possible to place any initiative or investment within a specific domain and understand its general purpose without needing to master every technical detail. A practical example of its usefulness is using it as a checklist in quarterly review meetings, to quickly check which domains have mature controls and which still require priority attention from leadership.

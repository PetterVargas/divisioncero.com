---
title: Paso 3 - Ejecución local
description: Levanta el proyecto en tu equipo para verificar que funciona correctamente
---

```bash tab="pnpm"
cd tu-proyecto
pnpm install
pnpm dev
```

```bash tab="npm"
cd tu-proyecto
npm install
npm run dev
```

```bash tab="yarn"
cd tu-proyecto
yarn install
yarn dev
```

Tu aplicación estará disponible en [http://localhost:3000](http://localhost:3000)

## Servidor MCP local

Mientras trabajas en local, tu asistente de IA puede consultar los controles y **tus** políticas a través del servidor MCP de Kudo, ya configurado en `.mcp.json`:

```bash tab="Claude Code"
claude
```

```bash tab="HTTP"
pnpm mcp:http   # http://localhost:3333/mcp
```

Continúa en el [Paso 4 - Trabajar con IA](/kudo/sgx/aprovisionamiento/trabajar-con-ia) para conectar otros asistentes, instalar las skills y usar los agentes.

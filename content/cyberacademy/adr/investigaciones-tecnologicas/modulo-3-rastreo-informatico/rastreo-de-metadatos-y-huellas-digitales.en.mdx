---
title: "Tracing Metadata and Digital Footprints"
description: "What files reveal unintentionally"
---

Metadata is information embedded in files, documents, images and emails that reveals details the author rarely shares intentionally, such as the software and version used to create the file, the exact date of creation or modification, the system username, the original folder path and even, in the case of photos, the GPS coordinates of the device that took them. For a technology investigator, extracting and analyzing this metadata with tools such as ExifTool or the operating system's own property viewers can turn a seemingly anonymous file into a solid lead about its author or the computer it was created on. The digital footprint isn't limited to file metadata: it also includes traces such as unique device identifiers, browser fingerprints and writing or style patterns that make it possible to correlate different pieces of evidence with the same actor. As with any tracing, it's essential to document the extraction method and preserve the original file without altering it, since later manipulation can modify or remove the metadata relevant to the case.

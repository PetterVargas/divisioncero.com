title: Step 9 - Deploy to production
description: Create the resource on your chosen platform and connect the repository
---

Create the resource on your chosen platform and connect the repository:

<Tabs items={["Azure Static Web Apps", "Cloudflare Pages"]}>
<Tab value="Azure Static Web Apps">

1. In the [Azure portal](https://portal.azure.com), search for **Static Web Apps** and click **Create**.
2. Choose your subscription and resource group and give the resource a name.
3. Under **Plan** select **Free** or **Standard** (Standard is required for auth with Entra ID).
4. Under **Deployment details** select **GitHub** and authorize access.
5. Select your organization, repository and branch (`main`).
6. Under **Build Details**:
   - **App location**: `/`
   - **Api location**: *(empty)*
   - **Output location**: `out`
7. Click **Review + create → Create**.

Azure will automatically create the `AZURE_STATIC_WEB_APPS_API_TOKEN` secret in your GitHub repository and run the first deployment.

Once deployed, configure a custom domain under **Custom domains** in the resource.

</Tab>
<Tab value="Cloudflare Pages">

1. In the [Cloudflare dashboard](https://dash.cloudflare.com), go to **Workers & Pages → Create → Pages**.
2. Click **Connect to Git** and authorize access to GitHub.
3. Select your repository and click **Begin setup**.
4. Configure the build:
   - **Project name**: `my-isms` (must match `projectName` in the workflow)
   - **Production branch**: `main`
   - **Build command**: *(empty — CI/CD already builds before deploying)*
   - **Build output directory**: `out`
5. Click **Save and Deploy**.

For a custom domain, go to **Custom domains** in your Pages project and add your corporate domain.

<Callout>
  If you use the GitHub Actions workflow with `cloudflare/pages-action`, leave the **Build command** empty in step 4 because the build already happens on the GitHub runner before uploading to Cloudflare.
</Callout>

</Tab>
</Tabs>

After the first successful deployment, every `push` to `main` will update the site automatically within a few minutes.

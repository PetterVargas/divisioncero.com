---
title: Step 4 - Adapt it to your organization
description: Customize the project with your organization's data, policies and branding
---

Before deploying, customize the project with your organization's data or personal topics. The main changes are in two files:

<Callout type="warn">
  This stage involves information specific to your company — organization name, repository, internal policies and branding. **The repository must be kept private** and not publicly accessible to avoid exposing your organization's sensitive data.
</Callout>

#### 1. Site identity — `lib/shared.ts`

```ts
export const appName = 'Your company name'; // [!code highlight]

export const gitConfig = {
  user: 'your-github-user',   // [!code highlight]
  repo: 'your-repository',      // [!code highlight]
  branch: 'main',
};
```

#### 2. ISMS content — `content/sgx/`

Edit the `.md` files inside `content/sgx/politicas-y-procedimientos/` with your organization's real policies. Each file corresponds to an ISMS document:

```
content/sgx/politicas-y-procedimientos/
├── politica-de-seguridad-de-la-informacion.md  ← edit
├── politica-de-gestion-de-accesos.md           ← edit
├── politica-de-gestion-de-riesgos.md           ← edit
└── ...
```

#### 3. Branding — `app/layout.config.tsx`

Replace the logo SVG with your organization's and update the navigation links as needed.

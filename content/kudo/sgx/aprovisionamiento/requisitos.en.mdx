---
title: Step 1 - Requirements
description: Tools and services needed to provision the ISMS
---

Before you start, make sure you have the following:

- [X] [Git](https://git-scm.com/install/) on your machine, to clone the information.
- [X] [Node.js 20+](https://nodejs.org/) and [pnpm](https://pnpm.io/installation), [npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) or yarn on your machine.
- [X] A code repository on [GitHub](https://github.com) or [GitLab](https://gitlab.com), to push the code and automate deployment.
- [X] A static hosting resource — we recommend [**Azure Static Web Apps**](https://azure.microsoft.com/en-us/products/app-service/static) or [**Cloudflare Pages**](https://pages.cloudflare.com/) (both have a free plan).
- [X] Optional: a corporate [Identity Provider (IdP)](https://en.wikipedia.org/wiki/Identity_provider) such as Microsoft Azure Entra ID or Google Workspace to protect the site so only internal employees can access it.

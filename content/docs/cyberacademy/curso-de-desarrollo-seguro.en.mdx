## What is this course for?

Team, good day: we're going to learn secure programming best practices throughout the software development lifecycle, getting ahead of problems and being that much-needed shift left, which, for those who don't know the term, means moving cybersecurity further to the left, anticipating it in any scenario; that's why we designed the following modules:

## What will I learn?

- 🚀 **Secure Development Fundamentals**: Learn the fundamentals of DevSecOps and threat modeling.
- 🚀 **Security in Design and Coding**: Apply secure coding principles and secrets management.
- 🚀 **Security Testing**: Detect vulnerabilities with static, dynamic and dependency analysis.
- 🚀 **Security in Integration and Deployment**: Secure your CI/CD pipelines, containers and infrastructure as code.
- 🚀 **Maintenance and Response**: Manage patches, bug bounty and continuous monitoring in production.

## Projects

With this course you'll create, optimize, automate or improve the following projects:

- 🚀 You'll implement pre-hooks to secure your code.
- 🚀 You'll generate a Software Bill of Materials (SBOM) and identify direct and transitive libraries.
- 🚀 You'll identify vulnerabilities locally with Static Application Security Testing (SAST) and Secret Scanning.
- 🚀 You'll configure dependency scanning and vulnerability detection.
- 🚀 You'll apply secure coding principles (OWASP Top 10).
- 🚀 You'll manage secrets and credentials securely in your code.
- 🚀 You'll implement validation and sanitization of user input.
- 🚀 You'll configure secure authentication and authorization in your applications.
- 🚀 You'll run automated security tests on your code.
- 🚀 You'll learn to handle and report vulnerabilities responsibly.

---
title: Paso 2 - Crear proyecto
description: Genera la estructura base del proyecto con el CLI de Kudo
---

Ejecuta el CLI de Kudo para generar la estructura base del proyecto:

```bash tab="pnpm"
pnpm create @divisioncero/kudo-app
```

```bash tab="npm"
npm create @divisioncero/kudo-app@latest
```

```bash tab="yarn"
yarn create @divisioncero/kudo-app
```

El CLI te preguntará:

1. El **nombre del proyecto**.
2. El **gestor de paquetes** (pnpm recomendado).
3. Si quieres incluir el **servidor MCP, los agentes y las skills de IA** (recomendado).

Y creará el directorio con:

- El **framework** completo (8 dominios y 36 controles).
- El **SGX**: 45 políticas, procedimientos y plantillas listos para adaptar.
- `.mcp.json`, `.claude/agents/` y `.claude/skills/` para [trabajar con IA](/kudo/sgx/aprovisionamiento/trabajar-con-ia).

<Callout title="Sin preguntas">
  Para automatizarlo (por ejemplo en CI), usa `pnpm create @divisioncero/kudo-app mi-sgx --yes`. Agrega `--no-ai` si no quieres la configuración de IA.
</Callout>

## What is this course for?

Security controls, posture and monitoring in AWS, Azure and GCP.

## What will I learn?

- 🚀 **Cloud Security Fundamentals**: Learn cloud service models and the shared responsibility model.
- 🚀 **Cloud Identity and Access Management**: Manage roles, policies and least privilege with cloud providers.
- 🚀 **Network Security and Configuration**: Segment virtual networks and detect cloud misconfigurations.
- 🚀 **Monitoring and Detection in Cloud Environments**: Monitor and detect threats specific to cloud environments.
- 🚀 **Cloud Compliance and Governance**: Manage compliance and governance for multicloud and hybrid strategies.

## Projects

With this course you'll create, optimize, automate or improve the following projects:

- 🚀 You'll implement secure network architectures with advanced segmentation and Zero Trust.
- 🚀 You'll deploy monitoring and intrusion detection systems in cloud and hybrid infrastructure.
- 🚀 You'll configure automated hardening for servers, containers and critical services.

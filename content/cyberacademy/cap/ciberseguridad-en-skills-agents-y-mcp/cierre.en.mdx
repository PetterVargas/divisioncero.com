## What we learned

We've brought you safely through the **Skills, Agents and MCP Cybersecurity Course**.

A quick recap of the places we visited and practiced:

- [X] What AI agents, Skills and the MCP protocol are
- [X] Use cases and typical architecture of agent-based solutions
- [X] Risk differences between traditional AI models and autonomous agents
- [X] Prompt injection and instruction manipulation risks
- [X] Risks of tools and permissions granted to agents
- [X] Exposure of sensitive data through agents and integrations
- [X] Security principles for connecting agents and MCP servers
- [X] Managing credentials and permissions in MCP integrations
- [X] Validating connected data sources and tools
- [X] The principle of least privilege applied to agents and skills
- [X] Sandboxing and limiting the scope of agent actions
- [X] Logging and traceability of actions executed by agents
- [X] Risk assessment before deploying agent-based solutions
- [X] Human oversight and approval mechanisms (Human in the Loop)
- [X] Continuous monitoring and response to anomalous agent behavior
